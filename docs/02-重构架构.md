# 重构架构

> 更新日期：2026-08-15

## 运行关系

```text
浏览器
  ├── Vue Router / 登录守卫
  ├── 管理 API / HttpOnly Cookie
  ├── SSE / Last-Event-ID
  └── 公共 API / API Key 或邮箱 Token
                 │
                 ▼
Go HTTP Server
  ├── auth.Service       管理员密码和会话
  ├── apple.Service      Apple 登录、2FA、检测和保活
  ├── mailbox.Service    邮箱、邮件、验证码、清理和删除
  ├── mailwatcher        IMAP IDLE 与账号级批量同步
  ├── scheduler          随机范围创建调度与恢复
  ├── httpapi.Server     路由、Cookie、SSE、导出和维护接口
  └── store.Store        SQLite、加密、事务和 change_log
                 │
                 ▼
             data/app.db
             data/app.db.key
```

## 后端边界

- `main.go`：进程入口、中文菜单、HTTP 生命周期、后台服务启动和优雅停止。
- `internal/config`：默认配置、JSON 覆盖、相对路径解析和配置权限。
- `internal/domain`：schema 4 领域对象、账号、邮箱、邮件、租约、设置和统计。
- `internal/store`：SQLite schema、迁移、查询、事务、字段加密、变更日志和数据库维护。
- `internal/auth`：首次设置、登录、退出、密码摘要与会话过期。
- `internal/httpapi`：HTTP 输入输出、鉴权、SSE、公共 API、导出与数据库维护。
- `internal/protocol`：Apple SRP、Apple Account、iCloud Web、Hide My Email、邮件与 IMAP 协议。
- `internal/apple`：组合登录、2FA、登录态检测、IMAP 保存和保活。
- `internal/mailbox`：创建、同步、验证码、全量/目标邮件清理和邮箱删除。
- `internal/mailwatcher`：按账号组织 IMAP IDLE、批量同步、主动唤醒和退避重连。
- `internal/scheduler`：随机范围调度、失败停止、持久化日志和重启恢复。
- `internal/webui`：嵌入前端生产产物并提供 SPA 回退。

## 前端边界

- `src/api/client.js`：统一 JSON、下载和中文错误处理。
- `src/composables/useAuth.js`：首次设置、登录、退出和路由认证状态。
- `src/composables/useRealtime.js`：单例 SSE、事件去重、重连和页面订阅。
- `src/router`：公开登录/验证码页面、受保护控制台和 404。
- `src/layouts/AppLayout.vue`：侧栏、顶部栏、公告、主题和移动端抽屉。
- `src/components`：卡片选择器、确认弹窗、提示、输入框和通用控件。
- `src/views`：控制台、Apple 账号、邮箱池、任务、导出、设置和公共验证码页面。

## SQLite 写入模型

SQLite 设置最大打开连接数和空闲连接数为 1，写操作通过事务串行提交。这样保留单机部署简单性，同时消除完整 JSON 文件重写产生的写放大。

```text
业务服务
  → Store SQL 查询/事务
  → UPSERT / DELETE 领域记录
  → 同事务追加 change_log
  → 提交事务
  → 唤醒 SSE 订阅者
```

账号级邮件同步使用 `ApplyMailboxSyncBatch` 在一个事务中写入邮件与多个邮箱游标；无实际变化时跳过通知。邮箱租约、运行状态和系统设置均直接持久化。

## 实时事件模型

`GET /api/realtime` 只允许已登录管理员访问。事件流提供：

- 数据库递增事件 ID。
- 心跳保活。
- `Last-Event-ID` 断线回放。
- 变更日志数量上限和后台裁剪。
- 页面级主题订阅与去重。

SSE 是刷新通知通道，不是业务数据唯一来源。页面收到事件后重新请求对应 API，最终一致性仍以 SQLite 为准。

## 后台任务模型

- IMAP watcher 按 Apple 账号合并同步，避免同账号多个邮箱重复登录和相互推进 UID。
- 创建调度每次启动使用独立 generation，旧 goroutine 不会覆盖新任务状态。
- 调度器随机选择轮次与账号间隔，任一创建失败即结束当前自动任务。
- Apple 全量邮件清理按账号排队，进度按隐私邮箱总数聚合。
- 邮箱彻底删除先清理目标邮件、再删远端邮箱、再删本地记录。

## 安全边界

管理员密码只保存 PBKDF2-SHA256 摘要，会话只保存随机 Token 的 SHA-256 摘要。Apple Cookie、登录态、IMAP 密码、邮箱 Token 和公共 API Key 由本机密钥 AES-GCM 加密。

控制台列表不回传邮箱 API Token 原文；完整导出是管理员主动操作，包含敏感字段。所有 `/api/` 响应统一使用 `Cache-Control: no-store`。公网边界仍需要 Host、限流、Origin/CSRF 和公共验证码访问控制。
