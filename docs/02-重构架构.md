# 重构架构

## 运行关系

```text
浏览器
  │ Vue Router / 登录守卫
  ▼
Go HTTP Server
  ├── auth.Service       PBKDF2 密码与会话 Token
  ├── httpapi.Server     认证、控制台、邮箱、设置和公共接口
  ├── apple.Service      Apple 登录态、2FA、检测和保活
  ├── mailbox.Service    隐私邮箱、邮件、验证码和远端操作
  ├── mailwatcher        按账号批量同步和 IMAP IDLE 监听
  ├── scheduler          周期创建调度
  ├── store.Store        并发安全的 JSON 状态和原子保存
  └── webui.Handler      embed.FS 静态资源与 SPA 回退
          │
          ▼
       data/state.json
```

## 后端边界

- `main.go`：进程入口、信号处理、后台任务生命周期和 HTTP 超时。
- `internal/config`：默认配置、配置文件覆盖和相对路径解析。
- `internal/domain`：状态、账号、邮箱、邮件、事件、分页和任务模型。
- `internal/store`：读写锁、状态规范化、统计、邮箱分页、设置保存、会话持久化。
- `internal/auth`：首次管理员设置、登录、退出、密码校验和会话过期。
- `internal/httpapi`：只负责 HTTP 输入输出、Cookie 和鉴权中间件。
- `internal/protocol`：Apple SRP、iCloud Web、Apple Account、IMAP 和 Hide My Email 协议调用。
- `internal/apple`：组合协议登录态、2FA、IMAP 保存和保活。
- `internal/mailbox`：组合隐私邮箱、邮件同步、验证码去重和远端删除确认。
- `internal/mailwatcher`：按 Apple 账号组织启用邮箱，使用 IMAP IDLE 接收新邮件事件，周期重检分组并在断线后退避重连。
- `internal/scheduler`：运行期定时创建任务和中文操作日志。
- `internal/webui`：从 `frontend/dist` 嵌入 Go 二进制，未知前端路径回退到 `index.html`。
- `cmd/migrate`：旧 `state.json` 到新 schema 的一次性导入。

## 前端边界

- `src/api/client.js`：统一 JSON 请求和错误处理。
- `src/composables/useAuth.js`：认证状态、首次设置、登录和退出。
- `src/router`：公开登录页、受保护控制台和 404。
- `src/layouts/AppLayout.vue`：顶部栏、主题、用户菜单和移动侧栏。
- `src/components`：侧栏、主题切换等可复用视图。
- `src/views`：控制台、Apple 账号、邮箱池、任务、设置和登录页面。

## 登录流程

```text
打开页面 → GET /api/auth/status
  ├─ setup_required=true → /login 显示首次设置
  └─ 已有管理员 → /login 显示登录
登录/设置成功 → HttpOnly Cookie → 访问受保护 API
退出 → 删除服务端会话 + 清除 Cookie
```

## 数据安全边界

控制台列表不返回邮箱 `api_token` 原文；公共 claim/lookup 在 API Key 校验后返回取码 URL，运行数据导出是管理员主动操作并包含登录态敏感字段。状态文件和临时文件使用 0600，目录使用 0700。当前版本是本地版，Cookie 的 `secure_cookie` 默认关闭；部署 HTTPS 时再打开。公网部署前应增加加密或系统密钥环保护。
