## 当前结论

单管理员个人使用闭环已经完成：Apple 登录、邮箱、邮件、验证码、自动创建、公共租约、导出、SQLite、SSE、后台监听和数据库维护均有对应实现。多用户、`/manage`、`state.json` 迁移和自动替换二进制属于明确移除或后置内容，不计为回归缺口。

## P0：正确性与公网门槛

1. 远端邮件删除的收件人匹配使用邮箱地址子串，需改为解析地址后的完整等值匹配。
2. 增加 Host allowlist，固定公网 `public_base_url`，只信任指定代理的转发头。
3. 登录、首次设置、公共 claim/lookup、公共验证码和取码增加分层限流。
4. 管理写接口增加 Origin/CSRF 校验。
5. 公共验证码增加访问凭证，统一不存在、停用和未收到验证码的失败响应。
6. Apple/iCloud 返回的服务 URL 只允许 HTTPS 和预期 Apple 域名。
7. 构建环境从 Go 1.26.5 升级到 Go 1.26.6 或更新补丁版本。

## P1：功能完整性

1. Apple 远端邮箱同步对账远端已删除记录，避免本地长期显示 `icloud_active=true`。
2. 服务层统一限制标签、备注、项目名、关键词和随机调度区间的最大值。
3. API Key 默认只通过 Header 使用，并提供邮箱 Token 轮换。
4. 完整运行数据导出增加二次确认、导出审计和可选密码保护。

## P2：维护与体验

1. 清理 29 项 Staticcheck：17 个 `ST1005`、9 个 `U1000`、2 个 `S1016`、1 个 `SA4006`。
2. 增加 CSP、Permissions-Policy 和通用弹窗 focus trap。
3. 评估管理员密码摘要成本，并支持登录时升级旧摘要。
4. 自动更新在确定产物签名、守护进程和失败回滚后实现。

## 明确移除

- 多用户注册、角色、用户管理页和 `/manage`。
- `state.json` 兼容读取和旧 JSON 迁移工具。
- 设置页固定邮箱每页数量。
- 固定单值创建间隔。
- 旧版手动插入测试邮件入口。
