# 项目结构

```text
iCloud-Privacy-Mail-v2/
├── main.go                             # 中文启动菜单、Go 服务主入口和后台任务生命周期
├── go.mod
├── cmd/
│   └── migrate/main.go                 # 旧状态迁移命令
├── internal/
│   ├── auth/service.go                 # 单管理员和控制台会话
│   ├── config/config.go                # 默认配置和 JSON 覆盖
│   ├── domain/model.go                 # schema 4 领域模型和邮箱租约
│   ├── protocol/                       # Apple、iCloud、IMAP 协议客户端
│   ├── apple/service.go                # Apple 登录态、2FA、检测和保活
│   ├── mailbox/service.go              # 隐私邮箱、邮件、验证码和远端删除
│   ├── mailwatcher/service.go          # 账号级批量同步、IMAP IDLE 和断线重连
│   ├── scheduler/service.go            # 周期创建调度和日志
│   ├── httpapi/server.go               # 控制台路由、Cookie 和鉴权
│   ├── httpapi/p2.go                   # 公共 API、调度 API 和导出 API
│   ├── store/                          # 并发安全 JSON 存储和查询
│   └── webui/
│       ├── embed.go                    # 嵌入前端构建产物
│       └── dist/                       # scripts/sync-web.sh 生成
├── frontend/                           # Vue 3 + Vite 页面
├── scripts/                            # 开发、构建和资源同步
├── docs/                               # 分析、架构、迁移和审计文档
├── config.example.json
├── README.md
└── REFACTOR_SUMMARY.md
```

## 运行关系

```text
main.go
  ├── httpapi.Server
  │     ├── auth.Service
  │     ├── apple.Service ── protocol.AuthFacade / ICloudClient
  │     └── mailbox.Service ── protocol.IMAP / ICloudClient
  ├── mailwatcher.Service ── mailbox.Service.SyncMailboxBatch
  └── scheduler.Service ── mailbox.Service.Create
              │
              ▼
        store.Store → data/state.json
```

## 命名约定

Go/JavaScript 的函数、方法、变量、类型和 Apple/API 协议键保持英文；面向用户的页面字段、提示、日志和注释使用中文。前端组件采用 PascalCase，API JSON 键使用 snake_case。
