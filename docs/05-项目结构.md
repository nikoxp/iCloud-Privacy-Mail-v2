## 运行调用关系

```text
main.go
  ├── store.Store ─────────────── data/app.db / data/app.db.key
  ├── httpapi.Server
  │     ├── auth.Service
  │     ├── apple.Service ─────── protocol.AuthFacade / ICloudClient
  │     └── mailbox.Service ───── protocol.IMAP / ICloudClient
  ├── mailwatcher.Service ─────── mailbox.Service / Store 批量事务
  └── scheduler.Service ───────── mailbox.Service.Create / runtime_states

浏览器
  ├── 普通 API ────────────────── httpapi.Server
  └── /api/realtime ───────────── change_log / SSE
```

## 数据文件

| 路径 | 作用 | 权限 |
| --- | --- | --- |
| `data/app.db` | SQLite 主数据库 | `0600` |
| `data/app.db.key` | AES-GCM 本机密钥 | `0600` |
| `data/backups/` | 在线备份目录 | `0700` |
| `config.json` | 本地运行配置 | `0600` |

## 命名约定

Go/JavaScript 的函数、方法、变量、类型和 Apple/API 协议键保持英文；面向用户的页面字段、提示、日志和注释使用中文。前端组件使用 PascalCase，API JSON 键使用 snake_case。
