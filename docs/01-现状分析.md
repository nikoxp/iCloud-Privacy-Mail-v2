# 现状分析

> 更新日期：2026-08-15

## 项目定位

当前项目是单管理员、本地优先的 Apple 隐私邮箱控制台，已从早期 JSON 状态与集中式处理器演进为 SQLite + 服务分层 + SSE 实时更新架构。它覆盖账号登录、邮箱创建和同步、IMAP 邮件、验证码、调度、公共租约、清理、删除、导出和数据库维护。

参考项目 `iCloud-Privacy-Mail` 的优势是协议能力完整、单二进制部署方便；早期主要问题是路由、协议、状态和页面逻辑集中在大型处理器中，修改远端删除或调度行为时难以局部验证。v2 保留协议和业务经验，重新划分模块边界。

## 当前技术状态

| 领域 | 当前实现 |
| --- | --- |
| 后端 | Go、`net/http`、独立服务层 |
| 前端 | Vue 3、Vue Router、Tailwind CSS、Lucide Vue |
| 数据 | SQLite WAL、schema 4、SQL 分页和事务 |
| 实时更新 | SSE、递增事件 ID、持久化变更日志和断线回放 |
| 认证 | 单管理员、PBKDF2-SHA256、HttpOnly Cookie |
| 敏感字段 | `data/app.db.key` + AES-GCM |
| Apple | Apple Account、iCloud Web、2FA、登录态检测和保活 |
| 邮件 | IMAP TLS、IDLE、账号级批量同步、验证码提取 |
| 后台任务 | 创建调度、Apple 邮件全量清理、邮箱删除队列 |

`data/app.db` 已成为唯一业务数据源，旧 `state.json` 不再保留兼容读取。数据库状态、备份、完整性检查和空间整理已经进入系统设置页面。

## 新版 UI 状态

新版页面使用紧凑卡片、统一字号、等高按钮和响应式表格：

- Apple 账号整行可打开登录态详情。
- 邮箱池有 ID、复选框、动态分页和表底页码。
- 邮箱、验证码支持点击复制。
- 详情使用普通字重，备注为单行编辑。
- 创建设置使用随机范围普通输入框。
- 控制台运行记录和创建页调度日志采用一致表格。
- 异步任务按资源禁用按钮，不阻塞无关操作。

新版截图位于 [`screenshots/ui/`](screenshots/ui/)。

## 当前主要缺口

功能闭环已经完成，下一阶段以公网安全与边界正确性为主：

1. 远端邮件删除需要从邮箱地址子串匹配改为完整地址等值匹配。
2. Host allowlist、可信代理与固定 `public_base_url`。
3. 登录、首次设置、公共取号、公共验证码和取码限流。
4. 管理写接口 Origin/CSRF 校验。
5. 公共验证码访问凭证与统一错误。
6. Apple/iCloud 返回服务 URL 的域名 allowlist。
7. 统一业务字段最大长度与调度范围上限。
8. 远端邮箱同步对账 Apple 侧已经删除的记录。

详细证据见 [`07-代码与安全审计.md`](07-代码与安全审计.md)。
