# 旧项目与页面参考分析

## 旧 Go 项目

旧目录 `iCloud-Privacy-Mail` 是一个功能完整但高度集中式的 Go 服务：`internal/app/server.go` 约 4830 行，路由注册、鉴权、业务流程、协议调用、响应组装和后台任务入口大量交织。状态集中写入 JSON `state.json`，模型同时包含用户、Apple 账号、登录态、隐私邮箱、邮件和调度设置。

旧路由同时包含以下几类职责：

| 类别 | 代表接口 |
| --- | --- |
| 页面与认证 | `/`、`/login`、`/manage`、`/api/auth/*` |
| 用户和管理 | `/api/admin/users/{id}`、`/api/manage/data` |
| Apple/iCloud 协议 | `/api/apple-account/login/*`、`/api/icloud/protocol-login/*`、`/api/icloud/session/*` |
| 邮箱池 | `/api/accounts`、`/api/mailboxes/*`、`/api/icloud/mailboxes/*` |
| 邮件和取码 | `/api/mailboxes/{id}/messages`、`/api/*/code` |
| 运行维护 | scheduler、导出、更新、健康检查 |

优点是功能齐全、单二进制容易部署；主要问题是单个处理器改动会牵涉状态、协议和页面，远程邮箱删除这类有副作用的操作也难以单独验证。

## `vue_demo` 页面

`vue_demo` 是 Vue 3 + Vite 的页面原型，提供了侧栏、Dashboard/Accounts/Tasks/Settings 四个视觉方向、卡片统计、暗色模式和响应式 Tailwind 样式。它的页面状态通过 `App.vue` 内的 `currentMenu` 切换，尚未接入后端路由；移动端菜单按钮也只是视觉占位。

新项目复用了它的布局层次和视觉密度，但改成 Vue Router 页面、后端 API 数据、登录路由守卫和真实移动端抽屉。图标依赖改为本地 `@lucide/vue`，避免 CDN 在离线环境失效。

## 重构后的边界

用户明确提出个人本地使用、默认页面重构、保留登录、移除 `/manage`，并说明后续可能增加 Apple 账号管理。v2 已在独立目录完成协议层、服务层、后台监听、调度和公共 API 的分层迁移。
