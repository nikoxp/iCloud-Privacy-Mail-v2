# 功能取舍

## 本轮保留

| 功能 | 新版状态 | 说明 |
| --- | --- | --- |
| 登录保护 | 已实现 | 单管理员首次设置，之后只登录 |
| 默认控制台 | 已实现 | Apple 账号、邮箱、邮件、可用数和事件统计 |
| Apple 账号页面 | 已实现 | 登录、2FA、登录态检测、IMAP、创建和同步 |
| 邮箱池页面 | 已实现 | 搜索、手动导入、点击复制、备注/状态快捷编辑、详情、邮件、取码、单个/批量远端清理和串行删除 |
| 设置页面 | 已实现 | 本地参数、后台开关、创建默认值和导出 |
| 暗色模式/响应式 | 已实现 | 借鉴 `vue_demo`，移动端侧栏可打开和关闭 |
| `/manage` | 已移除 | 后端 404，前端没有导航入口 |
| 旧状态迁移 | 已实现 | 单独的 `ipm-migrate` 命令 |

## 已迁移的运行能力

- Apple 登录、2FA、登录态刷新、隐私邮箱创建/同步/远程删除、IMAP 监听、验证码取码、定时调度和导出已直接暴露新接口。
- 已加入 GitHub Release、默认分支提交检查和公告中心；二进制自动替换继续作为部署方式确定后的独立决策。

邮箱远程删除始终保留以下业务约束：

1. 使用邮箱记录中的 `account_id` 找到对应 Apple 登录态。
2. 通过 `anonymous_id` 或邮箱地址读取 Apple 服务器列表。
3. 远端停用/删除后再次读取列表确认已不存在。
4. 只有确认成功才删除本地邮箱和邮件缓存；失败时保留本地记录并显示原因。

列表中的彻底删除额外遵循以下交互约束：

1. 每个邮箱都单独显示二次确认，不把提示本身当作任务结果。
2. 连续确认多个邮箱时进入串行队列，不并发调用 Apple。
3. 当前任务显示“删除中”，等待任务显示“排队中”，按钮保持固定宽度并显示旋转进度。
4. 顶部中央提示持续更新到队列结束，再展示成功、失败数量和最近错误。

邮箱池列表同时提供轻量快捷操作：点击邮箱文字复制地址；标签和备注分两行居中显示；点击备注或状态复用公共表单弹窗完成修改。备注字段使用可选值传输，因此提交空字符串可以清空已有备注。

## 个人本地版的选择

不引入多用户注册、角色管理和管理员用户页。公网 API Key 已作为可选配置接入；未来部署到公网时，在现有登录中间件上增加反向代理、Secure Cookie、CSRF 策略、审计日志和备份即可，不需要恢复 `/manage`。
