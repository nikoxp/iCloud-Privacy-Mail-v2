## 关键业务约束

### 邮件与邮箱删除

1. 全量邮件清理按 Apple 账号扫描所有邮件文件夹。
2. 进度分母使用参与账号下的隐私邮箱总数；邮箱没有邮件也需要完成扫描并计数。
3. 目标邮箱清理只处理收件人为该邮箱的邮件。
4. 彻底删除邮箱先清理目标邮件，再删除 Apple 云端邮箱。
5. 只有远端确认邮箱不存在后才删除本地邮箱和邮件。
6. 多个删除任务串行执行，失败保留本地记录并展示原因。

### 自动创建

1. 轮次间隔使用最小/最大分钟范围。
2. 同轮账号间隔使用最小/最大秒数范围。
3. 每次等待前重新生成范围内随机值。
4. 任一创建失败立即停止自动任务。
5. 配置、计数和最近日志持久化到 SQLite，服务重启可以恢复任务状态。

### 公共邮箱租约

1. `claim` 先把邮箱从 `available` 变为 `reserved`。
2. `project + request_id` 保证领取幂等。
3. 业务成功才调用 `commit` 进入 `used`。
4. 业务失败调用 `release`，超时也自动回收。
5. 等待人工确认时调用 `renew` 延长租约。

## 明确不保留

- 多用户注册、角色和用户管理后台。
- `/manage` 页面及其数据入口。
- `state.json` 兼容读取和旧 JSON 数据迁移工具。
- 设置页固定邮箱每页数量；页面改为按可视高度计算。
- 固定单值创建间隔；新配置只使用随机范围。
- 自动下载并替换正在运行的二进制。
